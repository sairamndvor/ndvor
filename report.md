1. Your positioning needs to become much sharper

The homepage currently opens with:

Transforming Business Through Innovation

and describes ndVOR as providing IT solutions, modernization and consulting across IBM, Microsoft and Open Source technologies.

There is nothing wrong with that, but thousands of IT companies can say essentially the same thing.

For an enterprise buyer, I would position ndVOR around something more specific:

Enterprise Modernization. Intelligent Commerce. AI-Powered Operations.

Then:

We help enterprises modernize legacy platforms, connect commerce and operational systems, unlock data with AI, and build scalable digital experiences.

Your IBM and legacy-system experience should become part of the differentiation rather than one technology reference buried in the copy.

For example:

Modernize without disrupting the systems that run your business.

That is a much stronger enterprise proposition if ndVOR's actual strength includes IBM i / AS400, modern applications, cloud, integrations and digital platforms.

20. Technical website requirements

There is also a technical layer that should accompany the visual redesign.

For production, I would require:

Performance

Core Web Vitals targets around:

LCP < 2.5s
INP < 200ms
CLS < 0.1

Use CDN delivery, optimized WebP/AVIF images, lazy loading, code splitting, caching and compressed assets.

SEO

Every page needs unique:

<title>
meta description
canonical URL
OpenGraph metadata
Twitter/social metadata

Add:

sitemap.xml
robots.txt

And schema such as:

Organization
Service
Article
BreadcrumbList
JobPosting

Accessibility

Target WCAG 2.2 AA:

keyboard navigation, sufficient contrast, accessible forms, semantic headings, ARIA where genuinely needed, alt text, visible focus states and screen-reader support.

Security

At minimum:

HTTPS
CSP
HSTS
X-Content-Type-Options
Referrer-Policy
Permissions-Policy
secure forms
server-side validation
spam protection
rate limiting

A GitHub Pages prototype is fine for development/demo purposes, but I would deploy the production corporate site through your controlled domain and production-grade delivery pipeline.
